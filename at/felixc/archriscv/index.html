Arch Linux RISC-V

This is an Arch Linux port to the RISC-V architecture.

Hardware baseline: RV64GC · ABI: lp64d

Hardware Support

The main linux kernel package has enabled support and has been tested for:

  • QEMU
  • HiFive Unmatched and HiFive Unleashed
  • PolarFire SoC Icicle Kit
  • VisionFive v2 and Milk-V Mars
  • Nezha D1

In addition, the [unsupported] repository has experimental kernel packages for LicheePi 4A (TH1520) and Milk-V Pioneer (SG2042).

Other boards, except those with AX45MP, may work with a BSP or custom kernel.

Porting Goal

This port applies patches on top of Arch Linux source packages. All patches are maintained in the patch repository .

The long-term goal is to upstream as many patches as possible, so that riscv64 ( riscv64gc ) can be added to Arch Linux itself as an alternative architecture.
